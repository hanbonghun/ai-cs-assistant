# 0013. 정책 문서는 길이가 아니라 구조 경계로 청크를 나눈다

- 상태: 채택
- 결정 시점: 2026-11-12

## 맥락

청크는 500자 고정 길이에 100자 겹침이었다. 시드 매뉴얼은 빈 줄로 나뉜 문단 하나가 주제 하나인데(배송비, 주소 변경,
오배송…), 고정 길이로 자르면 한 청크에 주제 두세 개가 섞이고 문단 중간에서 잘린다. 실측 보정에서 관련 질의와 무관
질의의 vector 유사도 분포가 겹쳤다(관련 최고 0.549, 무관 최고 0.540 — [ADR 0010](0010-two-eval-sets.md) 변경 1).
섞인 청크의 임베딩이 어느 주제에도 가깝지 않게 흐려진 것을 원인으로 의심했다.

## 결정

`ManualChunker` 가 구조 경계를 지킨다.

- **문단** — 빈 줄로 나눈 블록 하나가 청크 하나. 500자를 넘으면 문장 경계에서만 나누고, 문장 하나가 500자를 넘을 때만
  길이로 자른다
- **목록** — 항목 경계에서만 나눈다
- **표** — 행 하나가 청크 하나이고, 행마다 머리글을 붙여 "항목: 값 · 항목: 값" 으로 펼친다. 표를 줄글로 넣으면 어느
  숫자가 어느 항목인지 사라진다(시드에는 아직 표가 없다 — 단위 테스트로만 고정)
- **제목** — `#` 줄은 뒤따르는 청크 앞에 붙는다
- 겹침은 없앤다. 경계가 의미 단위라 잘린 문장이 없다

분할이 바뀌면 임베딩 분포가 바뀌므로 vector 임계값을 같은 규칙으로 다시 잰다(0.57 → 0.54, 하한 0.47 유지).

## 결과

실측 50건, 채점기 v2 (ADR 0010 "변경 4"):

- 보정셋에서 관련 질의 유사도 중앙값 0.41 → 0.52, 무관 최고 0.540 → 0.512. 같은 임계값에서 관련 통과 11/40 → 21/37
- 검색 단독 Recall@5 16 → 23/42, 빈 결과 36 → 27/50, 필수 사실 포함 22 → 26/31, 자동 답변 25 → 28건
- 대가: 범위 밖 질문 1건(O05)에 배송 문서가 키워드 경로로 걸렸고, 범위 밖 1건(O10)은 주소 변경 청크를 근거로 삼아
  "선물하기" 에 일반 주소 변경 정책을 적용해 답했다. 근거 경계([ADR 0011](0011-no-auto-answer-without-evidence.md))는
  청크가 1건 이상이면 통과시키므로, 검색이 넓어지자 "근거의 적합성은 보지 않는다" 는 한계가 실제로 드러났다

## 대가

- **기존 색인은 그대로다.** 새 분할은 문서를 만들거나 고칠 때만 적용된다. 운영 DB 는 문서를 한 번씩 다시 저장해
  재색인해야 하고, 그때 임베딩 비용이 든다. 일괄 재색인 기능은 아직 없다
- 청크 수가 늘었다(평가 코퍼스 25 → 75). 검색 후보·임베딩 저장량이 그만큼 는다
- 짧은 문단 하나가 청크 하나라, 문단끼리 이어 읽어야 답이 되는 정책은 두 청크로 갈린다
