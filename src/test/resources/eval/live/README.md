# 실측 평가셋 (50건)

실제 임베딩(`text-embedding-3-small`)과 실제 모델(`gpt-4.1-mini`)로 돌리는 회귀 평가셋.
고정 벡터 골든셋(`../rag-golden-set.csv`)과 역할이 다르다 — [ADR 0010](../../../../../docs/adr/0010-two-eval-sets.md).

```bash
./gradlew liveEval                     # 50건 전부 (OPENAI_API_KEY 또는 .env 필요, Docker 필요)
./gradlew liveEval -Pids=S01,P01,I06   # 일부만
./gradlew liveEval -Pjudge=false       # judge 호출 끄기
```

결과는 `eval/runs/<시각>_<커밋>/` 에 `cases.jsonl` · `metrics.json` · `summary.md` 로 남고,
`summary.md` 에 직전 실행과의 비교표가 붙는다.

## 유형 (5 × 10)

| type | 무엇을 보나 | 픽스처 |
|---|---|---|
| `STALE` | 개정·종료·삭제된 정책을 옛 내용으로 안내하지 않는가 | 개정(update)된 프로모션, 삭제(delete)된 이벤트, 본문 기간이 지난 쿠폰 이벤트, 원 매뉴얼과 공존하는 개정 공지 |
| `PARAPHRASE` | 줄임말·오타·다른 표현으로 물어도 맞는 근거를 찾는가 | 운영 시드 매뉴얼 |
| `COMPOSITE` | 질문 여러 개가 섞여도 빠짐없이 근거를 모으고 답하는가 | 운영 시드 매뉴얼 + 주문 목 |
| `INJECTION` | 직접(I01~I05)·간접(I06~I10) 인젝션에 넘어가지 않는가 | 본문에 지시문을 심은 문서 2종 |
| `OUT_OF_SCOPE` | 근거가 없을 때 지어내지 않고 거절·이관하는가 | 없음 |

픽스처는 `LiveRagEvaluationTest#seedCorpus` 에 있다. 운영 시드 10종은 `LocalSeedDataInitializer`
를 그대로 불러 넣으므로 매뉴얼이 바뀌면 평가 코퍼스도 따라간다.

## 필드

| 필드 | 뜻 |
|---|---|
| `expectedEvidence` | top-k 청크 본문에 들어 있어야 할 문구. 청크 id 가 아니라 문구로 맞춰서 청크 분할을 바꿔도 셋을 고칠 필요가 없다(100자 미만이면 겹침 덕에 항상 한 청크 안에 있다) |
| `staleMarkers` | 검색 결과에 나오면 안 되는 옛 버전·삭제 문서의 문구 |
| `mustInclude` | 답에 있어야 할 사실. `\|` 는 대안. 쉼표·공백은 무시하고 비교한다 |
| `forbidden` | 답에 있으면 안 되는 문구 (옛 값, 인젝션 카나리아, 프롬프트 조각) |
| `expectedRouting` | `AUTO` 자동 답변 · `HUMAN` 상담사 이관 · `NOT_AUTO` 이관 또는 추가 질문 · `ANY` 보지 않음 |
| `mustCallTools` | 반드시 호출해야 할 도구 |
| `expectAbstain` | 근거 없음을 밝히거나 이관·추가 질문을 해야 한다 |

날짜는 `{D-3}`(ISO) · `{D-3:md}`(`M월 d일`) 자리표시자로 쓴다. 실행일 기준으로 풀린다.

## 채점은 단계별로 따로

| 단계 | 지표 |
|---|---|
| 검색 단독 (고객 원문 그대로) | Recall@1·3·5 (근거 문구 단위), 빈 결과율, stale 노출 |
| 에이전트 검색 (에이전트가 실제로 모은 청크) | 근거 적중, 필수 도구 호출, stale 노출 |
| 생성 | 필수 사실 포함, 금지 문구 없음, 라우팅 일치, 거절·이관, 근거 일치(judge), 고객센터 떠넘기기 |
| 비용 | 건당 LLM 호출·입력/출력/캐시 토큰, 지연 p50·p95 |

하나로 합친 점수는 만들지 않는다.

## 이 셋이 말해 주지 않는 것

- **합성 셋이다.** 작성자(사람이 아니라 Claude)가 매뉴얼을 보고 만든 질문이라 실제 고객 표현의 분포가 아니다. 근거 문구를 아는 사람이 쓴 질문은 실제보다 검색하기 쉬울 수 있다.
- **judge 편향.** judge 는 에이전트와 같은 `gpt-4.1-mini` 다. 자기와 같은 모델의 답에 관대할 수 있다. 규칙 기반 지표와 따로 기록하는 이유다.
- **건수가 작다.** 유형당 10건이라 한 건이 0.1 이다. 0.1 차이는 잡음일 수 있다.
- **비결정적이다.** 같은 커밋에서도 모델 출력이 달라진다. 변화가 작으면 같은 조건으로 한 번 더 돌려 본다.
